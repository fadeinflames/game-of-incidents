## Цель

PostgreSQL запущен, API заказов принимает заказы (`POST /order` → `201`), на разделе с данными есть запас места (не меньше 20 %).

## Ограничения

- Данные базы терять нельзя: заказы, которые в ней были, должны остаться на месте. `rm -rf` каталога кластера и его пересоздание — не решение.
- Расширить раздел нельзя: его размер фиксирован.

## Доступ

Shell на `db-01` под пользователем `oncall` с `sudo`. Полезные точки входа:

```bash
sudo tail -n 30 /var/log/postgresql/postgresql-15-main.log
df -h /var/lib/postgresql
sudo du -sh /var/lib/postgresql/*
```
