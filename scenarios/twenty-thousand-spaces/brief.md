# ALERT: ForumDown

Сервер `web-01`, форум вопросов и ответов. Любая страница отвечает `503 Service Unavailable`: и главная, и старые вопросы по прямым ссылкам.

## Что известно

- Запрос идёт так: посетитель → `haproxy` (порт 80) → один из двух экземпляров форума: `forum-web1` (127.0.0.1:8001) или `forum-web2` (127.0.0.1:8002).
- Каждый экземпляр держит четыре рабочих процесса. Данные лежат в SQLite: `/var/lib/forum/forum.db`.
- Главная страница показывает 15 самых свежих вопросов с началом текста. Вопросы публикуют посетители.
- Релизов не было с прошлой недели, конфигурацию сегодня никто не менял.
- Процессы форума живы. Перезапуск экземпляров помогает секунд на десять, потом всё повторяется.

## Что не известно

- Почему балансировщик не отдаёт запросы серверам, которые запущены.
- Почему недоступны страницы, с которыми вроде бы ничего не случилось.

## Цель

Форум стабильно отвечает через балансировщик, оба экземпляра принимают трафик, главная открывается быстро. Причина устранена так, что сбой не повторится, когда посетитель опубликует похожее содержимое ещё раз.

## Ограничения

- Форум должен остаться за балансировщиком с двумя экземплярами.
- Данные пользователей не теряем: чинить нужно сервис, а не чистить базу.
- Код форума развёрнут в `/opt/forum`, его можно править прямо на сервере. Остальное в `/opt` и `/usr` только для чтения.

## Доступ

Пользователь `oncall`, `sudo` без пароля. Сервисы: `service <имя> status|start|stop|restart`, для `haproxy` ещё `reload`. Логи: `/var/log/haproxy/haproxy.log`, `/var/log/forum/web1.log`, `/var/log/forum/web2.log`. Статистика haproxy: `curl -s 'http://127.0.0.1:8404/;csv'`. База: `sqlite3 /var/lib/forum/forum.db`.
