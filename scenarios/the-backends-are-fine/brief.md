# ALERT: EngineListErrors

Сервер `api-01`, сервис перевода документов. Клиенты волнами получают ошибку «Engines are temporarily unavailable»: список движков не загружается, перевод не запускается. Через минуту-другую всё проходит само, потом повторяется.

## Что известно

- Запрос идёт так: клиент → `nginx` (порт 80) → `catalog-api` (127.0.0.1:8080). Любая работа клиента начинается с `GET /v1/engines`: без списка движков перевод не запустить.
- Перед ответом `catalog-api` узнаёт подписку аккаунта в сервисе `entitlements`. Сервис принадлежит команде биллинга, ходить к нему положено через её шлюз `127.0.0.1:9000`.
- Движки перевода: `engine-std` (127.0.0.1:9201) и `engine-pro` (127.0.0.1:9202). У каждого есть `GET /healthz`.
- Клиенты: плагин для редактора `translator-plugin` и консольная утилита `translator-cli`. Аккаунт клиент передаёт в заголовке `X-Account`.
- С утра пользователям автоматически приходит обновление плагина: версия 2.9.0 вместо 2.8.4. Оно уже у большинства.
- Серверную часть сегодня не выкатывали, настройки не меняли.

## Что не известно

- Почему список движков не отдаётся, если движки запущены.
- Почему ошибки идут волнами и что изменилось именно сегодня.

## Цель

Пользователи получают список движков без ошибок и в спокойные минуты, и в пик нагрузки. Каждый аккаунт видит ровно те движки, на которые у него есть подписка. Проверка идёт около 45 секунд и сама создаёт пик нагрузки, так что «сейчас тихо» решением не считается.

## Ограничения

- Сервис `entitlements` и его шлюз (порт 9000, файл `/etc/nginx/sites-available/entitlements-gw`) принадлежат команде биллинга. Их настройки не меняем, в обход шлюза к сервису не ходим.
- Отозванная подписка должна перестать действовать не позже чем через 5 минут после отзыва: это условие договора с клиентами.
- Работать должны пользователи обеих версий плагина. Блокировать или ограничивать клиентов нельзя, откат версии 2.9.0 займёт около суток.
- Код в `/opt` только для чтения. Настройки `catalog-api` (`/etc/catalog-api/catalog-api.env`) и нашего `nginx` (`/etc/nginx/sites-available/edge`) менять можно.

## Доступ

Пользователь `oncall`, `sudo` без пароля. Сервисы: `service <имя> status|start|stop|restart`, для `catalog-api` и `nginx` ещё `reload`. Логи: `/var/log/nginx/`, `/var/log/catalog-api/`, `/var/log/entitlements/`, `/var/log/engine-std/`, `/var/log/engine-pro/`. Запросить список руками:

```bash
curl -s -H 'X-Account: acc-1500' localhost/v1/engines
```
