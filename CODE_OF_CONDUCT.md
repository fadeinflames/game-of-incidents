# Правила поведения / Code of Conduct

Мы принимаем **Contributor Covenant, версия 2.1** как правила поведения проекта:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/ (русский перевод: https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/).

Коротко: уважай людей, обсуждай идеи, а не личности, не используй оскорбления, преследование и чужие личные данные. Правила действуют в issues, pull requests, обсуждениях и любых других местах проекта.

Сообщить о нарушении: личное сообщение сопровождающему https://t.me/fadeinflames или приватный отчёт в GitHub (Security → Report). Сообщения рассматриваются конфиденциально. Последствия, вплоть до бана, определяет сопровождающий по шкале Enforcement Guidelines из Contributor Covenant 2.1.

---

We adopt the **Contributor Covenant, version 2.1** as the code of conduct of this project: https://www.contributor-covenant.org/version/2/1/code_of_conduct/.

In short: respect people, discuss ideas rather than individuals, no harassment, no insults, no publishing other people's private data. It applies in issues, pull requests, discussions and any other project space. Report violations to the maintainer by direct message at https://t.me/fadeinflames or as a private report on GitHub; reports are handled in confidence, and the maintainer applies the Enforcement Guidelines of the Covenant.
